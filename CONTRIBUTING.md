# Contributing to Nano Empire Tollbooth

Thanks for your interest in contributing!

## Development Setup

```bash
git clone https://github.com/roblambert9/nano-empire-tollbooth.git
cd nano-empire-tollbooth
pip install -e ".[dev]"
pytest
```

## Pull Requests

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a PR
